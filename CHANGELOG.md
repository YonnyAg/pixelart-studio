# Cambios

## 1.0.0 — 2026-10-20

- Conversión de imágenes a PixelArt con cuadrícula, escala y paleta configurables.
- Presets persistentes con nombre, reemplazo y eliminación.
- Comparación lado a lado con zoom y desplazamiento sincronizados.
- Historial de 20 creaciones, eliminación individual y vaciado completo.
- Exportación PNG, WebP y JPEG.
- Icono propio y distribución portable para Windows x64.
- Compilación reproducible mediante script y GitHub Actions.
