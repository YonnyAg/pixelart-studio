# Contribuir a PixelArt Studio

Las mejoras y correcciones son bienvenidas. Para cambios grandes, abre primero
un Issue describiendo el problema y el comportamiento esperado.

1. Crea un fork y una rama para tu cambio.
2. Usa Python 3.11 y un entorno virtual; instala `requirements-dev.txt`.
3. Mantén separadas la conversión, la persistencia y la interfaz.
4. Añade pruebas cuando cambies comportamiento de procesamiento o almacenamiento.
5. Ejecuta las pruebas del README. Si cambias recursos o empaquetado, construye
   y verifica los ejecutables en Windows.
6. Abre una pull request con el problema, el cambio y las comprobaciones realizadas.

No incluyas imágenes privadas, bases de datos personales, credenciales, el entorno
virtual ni ejecutables generados. El proyecto se distribuye bajo licencia MIT;
consulta `LICENSE` y conserva los avisos de terceros.
